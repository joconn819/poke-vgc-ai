Play a random team matchup

  1. Start the local Showdown server and bot once (commands below). The bot uses Round466 and the Round402 team selector.
  2. Open the server, sign in, and choose a legal team for gen9championsdoubles2026mcclosed. To vary your side between games, select or build a different legal team in Showdown.
  3. Use the copied challenge command in the Showdown lobby. The bot prepares a fresh team for each match and selects four Pokémon.
/challenge VGCCheckpointBot, gen9championsdoubles2026mcclosed

The bot picks four from a newly generated six-Pokémon team. Your own team is selected in Showdown. The match runs entirely on the local server.

Start the latest checkpoint bot

On the machine hosting Showdown, run this from the project directory after setting HOST_IP to that machine’s private network address:

HOST_IP=192.168.1.153
scripts/run_local_showdown_lan.sh "$HOST_IP" 8001

In a second terminal, start the bot with the latest finished checkpoint:

PYTHONPATH=. POKEMON_SHOWDOWN_PATH=/home/justin/p/poke_learning/pokemon-showdown \
  venv/bin/python scripts/run_lan_bot.py \
  --server-host "$HOST_IP" --port 8001 \
  --username VGCCheckpointBot \
  --checkpoint training/outputs/phase12_headless/round466_round430_opening14_teacher_pool430_464_465_20k_20261031/checkpoints/latest.pt \
  --team-selection-checkpoint training/outputs/phase12_headless/round402_selector_currentdata_8ep_20261030/selector_candidate.pt

The published progress site cannot host the Showdown battle process or access checkpoint files on the training machine, so the server and bot need to be running on a machine you control. These commands use the Round466 checkpoint shown above.
